# Global Superstore Sales Dashboard

## Project Overview
This project analyzes Global Superstore sales data using Microsoft Excel.

## Analysis Performed
- Descriptive Statistics
- Mean
- Median
- Mode
- Variance
- Total Revenue
- Sales by Category
- Yearly Sales Trends
- Department-wise Revenue
- Pivot Tables
- Interactive Dashboard

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Descriptive Statistics
